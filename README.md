## 🚀 Getting Started

### Prerequisites

- Install [nvm](https://github.com/nvm-sh/nvm) (Node Version Manager)

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
```

- Install Node.js (Recommended version)

```bash
nvm install 22.15.0
nvm alias default 22.15.0
nvm use 22.15.0
```

- Ensure npm is available.

```bash
npm --version
```

### Clone the Repositoy

```bash
git clone https://github.com/oconnellj2/oconnellj2.github.io.git
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

### The web app is now running at

```bash
http://localhost:5173/
```
